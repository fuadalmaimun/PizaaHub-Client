# 🍕 PizzaHub – Online Pizza Ordering Platform

**PizzaHub** is a modern online pizza ordering platform where customers can explore delicious pizzas, place orders, and manage their purchases. Vendors can manage their menu items and orders, while admins can oversee the entire platform.

## 🚀 Key Features

### 👤 Customer
- Browse pizzas and explore different categories.
- View pizza details and pricing.
- Add items to cart and place orders.
- Manage personal orders.
- Secure online payments with Stripe.

### 🏪 Vendor
- Manage vendor profile and dashboard.
- Add, update, and manage menu items.
- Activate or deactivate menu items.
- Manage incoming customer orders.
- Choose between Free and Premium subscription plans.
- Premium vendors get unlimited active items, a Premium badge, and featured menu placement.

### 🛡️ Admin
- Manage users and vendors.
- Monitor and manage menu items.
- Oversee customer orders.
- Manage platform activities.

## 💳 Subscription Plans

## ⚙️ Installation & Setup

### 1. Clone the repositories

Clone the frontend and backend repositories separately.

### 2. Install dependencies

Run the following command in both project directories:

```bash
npm install
```

### 3. Configure Environment Variables

Create a `.env` file in both frontend and backend directories and configure the required environment variables.

### 4. Run the Backend

```bash
npm run dev
```

### 5. Run the Frontend

```bash
npm run dev
```

Open `https://pizzahub-client.vercel.app` in your browser.

## 🔐 Security

- Sensitive credentials and API keys are stored in environment variables.
- Environment files are excluded from version control.
- Authentication and role-based access control protect user activities.
